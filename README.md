## Hiya!

I'm Daniel. Around the interwebs you might know me as danieliscrazy or dld. I like tech, in particular hardware! I make cool hardware projects sometimes! Here's some of the cool stuff I've made:

- **[Jukebox](https://github.com/danieliscrazy/Jukebox):** A fully functional IRL Minecraft jukebox that uses NFC tags to detect discs!
- **[Robert the Minion](https://github.com/pizzalover125/minion-hackathon-submission/blob/main/README.md):** An interactive minion from Despicable Me that can wave, blink, and speak! Robert was made for [Undercity](http://undercity.hackclub.com/), a 4 day hardware hackathon at GitHub HQ, where he placed 13th out of 75 projects.
- **[SlackPager](https://github.com/danieliscrazy/SlackPager/):** A pager-style device that sends and received messages from Slack!
- **[Big Boy With A Fez](https://devpost.com/software/big-boy-with-a-fez):** A big boy that, you guessed it, wears a fez! This was made for HackNYU Fall 2025, where it came in 3rd in Entertainment!
- **[Flatpack](https://github.com/danieliscrazy/Flatpack):** A box that can feel pain (and is kind of a prick). Flatpack was my first hackathon project, made for Scrapyard NJ, where he won Funniest Project.

I've got more cool projects in the works, so be on the lookout! If I'm not making stuff here, I'm doing things in [Hack Club](https://hackclub.com/), which is a non-profit dedicated to motivating high schoolers to code through grants and events, and a global community of teenagers who like to code and build technical projects (so TL;DR, if you are a teen between 13-18, and you want free stuff for coding and making projects, come join us!!). I've done various things there, but my current project is [Horizons](https://horizons.hackclub.com/), a platform for Hack Club's most accessible hackathons yet, and Horizons Nexus, a 250-person hackathon in San Francisco this June. Come make some projects and join us!

There's a lot more I could talk about, so I'll update this later. See ya around!
